# 04 — Behaviors, with per-Class enabling

**What to build:** A teacher decides what they track. Participation, positive behavior,
redirect and absent exist by default; up to six Behaviors total, each with a name, a
colour, and a mode of either tallies or toggles. Each Class turns on the subset that
appears on its popup — the full list still exists everywhere else.

**Blocked by:** 03 — Classes and roster import

**Status:** ready-for-agent

- [ ] The four default Behaviors exist for a new teacher, with absent set to toggles and dark grey
- [ ] A teacher can add, rename, recolour, reorder and delete Behaviors
- [ ] A seventh Behavior cannot be created, and the limit is explained rather than silently enforced
- [ ] Each Behavior can be switched between tallies and toggles
- [ ] Each Class can enable and disable Behaviors independently of the others
